## 📖 About

Termux Package Manager is a modern alternative to the default `pkg` command. Built with Python, it offers:

- ✨ **Beautiful colored output** - Easy to read and navigate
- 🚀 **Fast parallel downloads** - Multiple packages at once
- 🔧 **Automatic dependency resolution** - No more manual installs
- 💾 **Lightweight** - Only 48KB, minimal resource usage
- 📦 **3000+ packages** - Access to the complete Termux repository
