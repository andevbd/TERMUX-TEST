## 📥 ইনস্টলেশন গাইড | Installation Guide

### 📱 **Termux (Android)**

<details>
<summary><b>🔽 ক্লিক করে বিস্তারিত দেখুন</b></summary>

#### ধাপ ১: Termux ইনস্টল করুন
```bash
# F-Droid থেকে Termux ইনস্টল করুন (Play Store ভার্সন কাজ নাও করতে পারে)
# https://f-droid.org/repo/com.termux_118.apk
```

ধাপ ২: Termux আপডেট করুন

```bash
pkg update && pkg upgrade -y
```

ধাপ ৩: Python ইনস্টল করুন

```bash
pkg install python python-pip curl wget git -y
```

ধাপ ৪: টুল রান করুন (৩টি পদ্ধতি)

পদ্ধতি ১: ওয়ান-লাইনার (সহজ)

```bash
curl -sSL https://raw.githubusercontent.com/andevbd/TERMUX-TEST/main/tst.py | python
```

পদ্ধতি ২: গিট ক্লোন

```bash
git clone https://github.com/andevbd/TERMUX-TEST.git
cd TERMUX-TEST
python tst.py
```

পদ্ধতি ৩: গ্লোবাল ইনস্টল (যেকোনো জায়গা থেকে রান)

```bash
cp tst.py $PREFIX/bin/pkg-manager
chmod +x $PREFIX/bin/pkg-manager
# এখন যেকোনো জায়গা থেকে রান করুন:
pkg-manager
```

স্টোরেজ পারমিশন দিন (যদি দরকার হয়)

```bash
termux-setup-storage
# তারপর Allow পারমিশন দিন
```

</details>

☁️ VPS/ক্লাউড সার্ভার

<details>
<summary><b>🔽 ক্লিক করে বিস্তারিত দেখুন</b></summary>

সকল VPS প্রোভাইডারের জন্য সাধারণ নিয়ম

```bash
# SSH দিয়ে VPS এ কানেক্ট করুন
ssh root@your-vps-ip
# অথবা
ssh username@your-vps-ip

# সিস্টেম আপডেট
sudo apt update && sudo apt upgrade -y

# Python ও টুলস ইনস্টল
sudo apt install python3 python3-pip curl wget git -y

# টুল ডাউনলোড ও রান
cd /opt
sudo git clone https://github.com/andevbd/TERMUX-TEST.git
cd TERMUX-TEST
sudo python3 tst.py
```

ব্যাকগ্রাউন্ডে রান করানো (ডিসকানেক্ট後ও চলবে)

পদ্ধতি ১: nohup ব্যবহার করে

```bash
nohup python3 tst.py > output.log 2>&1 &
# লগ দেখতে: tail -f output.log
# প্রসেস কিল করতে: ps aux | grep tst.py && kill [PID]
```

পদ্ধতি ২: screen ব্যবহার করে

```bash
screen -S pkg-manager
python3 tst.py
# Ctrl+A, তারপর D প্রেস করলেই ডিটাচ হবে
# রিঅ্যাটাচ করতে: screen -r pkg-manager
```

পদ্ধতি ৩: tmux ব্যবহার করে

```bash
tmux new -s pkg-manager
python3 tst.py
# Ctrl+B, তারপর D প্রেস করুন
# রিঅ্যাটাচ: tmux attach -t pkg-manager
```

সিস্টেমড সার্ভিস বানান (অটোস্টার্ট)

```bash
sudo nano /etc/systemd/system/pkg-manager.service
```

```ini
[Unit]
Description=Universal Package Manager
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/TERMUX-TEST
ExecStart=/usr/bin/python3 /opt/TERMUX-TEST/tst.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable pkg-manager
sudo systemctl start pkg-manager
sudo systemctl status pkg-manager
```

⚙️ কনফিগারেশন | Configuration

কনফিগ ফাইল তৈরি

```bash
# ~/.pkg-manager/config.json
{
    "auto_update": true,
    "parallel_downloads": 4,
    "cache_dir": "/tmp/pkg-cache",
    "log_level": "INFO",
    "theme": "dark",
    "language": "en"
}
```

এনভায়রনমেন্ট ভেরিয়েবল

```bash
export PKG_MANAGER_DEBUG=1
export PKG_MANAGER_NO_COLOR=0
export PKG_MANAGER_CACHE_SIZE=1024
```

🔧 ট্রাবলশুটিং | Troubleshooting

সাধারণ সমস্যা ও সমাধান

<details>
<summary><b>❌ 'python' কমান্ড কাজ করছে না</b></summary>

```bash
# Windows: Python PATH এ আছে কিনা চেক করুন
where python

# Linux/macOS: Python3 ব্যবহার করুন
python3 tst.py

# Termux: Python ইনস্টল করুন
pkg install python
```

</details>

<details>
<summary><b>❌ পারমিশন ডিনাইড এরর</b></summary>

```bash
# Linux/macOS: চালানোর অনুমতি দিন
chmod +x tst.py

# অথবা sudo দিয়ে রান করুন
sudo python3 tst.py
```

</details>

<details>
<summary><b>❌ নেটওয়ার্ক কানেকশন এরর</b></summary>

```bash
# ইন্টারনেট চেক করুন
ping google.com

# প্রক্সি থাকলে সেট করুন
export HTTP_PROXY=http://proxy:8080
export HTTPS_PROXY=http://proxy:8080
```

</details>

<details>
<summary><b>❌ মেমোরি কম থাকলে</b></summary>

```bash
# ছোট ডিভাইসের জন্য
python tst.py --low-memory

# অথবা পেজফাইল বাড়ান
# (VPS এর জন্য)
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
```

</details>

❓ প্রায়শই জিজ্ঞাসিত প্রশ্ন | FAQ

<details>
<summary><b>📱 Termux এ কাজ করে?</b></summary>
হ্যাঁ, সম্পূর্ণ সাপোর্টেড। F-Droid থেকে Termux ইনস্টল করতে হবে (Play Store ভার্সন নয়)।
</details>

<details>
<summary><b>🪟 Windows 7 এ কাজ করবে?</b></summary>
Windows 10 বা তার উপরে রেকমেন্ডেড। Windows 7 এ Python 3.8+ কাজ করে না।
</details>

<details>
<summary><b>🍓 Raspberry Pi Zero তে কাজ করবে?</b></summary>
হ্যাঁ, কিন্তু ধীর গতিতে। Pi 3/4/5 রেকমেন্ডেড।
</details>

<details>
<summary><b>☁️ ফ্রি টিয়ার VPS এ কাজ করবে?</b></summary>
হ্যাঁ, AWS Free Tier, Google Cloud Free Tier, Oracle Free Tier সব কাজ করে।
</details>

<details>
<summary><b>🔒 এটা কি নিরাপদ?</b></summary>
হ্যাঁ, কোড সম্পূর্ণ ওপেন সোর্স। আপনি চাইলে নিজে চেক করতে পারেন।
</details>

<details>
<summary><b>📦 কাস্টম প্যাকেজ অ্যাড করা যাবে?</b></summary>
হ্যাঁ, কনফিগ ফাইলে অ্যাড করতে পারেন।
</details>

2. ব্রাঞ্চ তৈরি করুন - git checkout -b feature/amazing
3. কমিট করুন - git commit -m 'Add amazing feature'
4. পুশ করুন - git push origin feature/amazing
5. পুল রিকোয়েস্ট করুন - GitHub এ PR ওপেন করুন

pip install -r requirements-dev.txt
